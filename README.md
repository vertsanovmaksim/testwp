# Фотостудія «Простір Обухів» — демо-сайт на WordPress

Демо для показу, що повноцінний сайт за ТЗ (див. [CLAUDE.md](CLAUDE.md)) збирається на власній темі WordPress без page builder'ів і запускається через **WordPress Playground** без хостингу.

- Тема: [`theme/prostir`](theme/prostir)
- Blueprint для публічного посилання: [`blueprint.json`](blueprint.json)
- Blueprint для локальної розробки: [`blueprint.local.json`](blueprint.local.json)

## Публічне посилання

Репозиторій публічний, тому Playground ставить тему прямо з GitHub (`git:directory`), а сідер створює сторінки, меню, пакети, портфоліо, відгуки й фото:

```
https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/vertsanovmaksim/testwp/main/blueprint.json
```

Перше завантаження триває 30–60 секунд (WordPress + PHP у браузері + імпорт 55 фото). Відкривається головна, адміністратор уже залогінений (`/wp-admin/`).
Усе живе в пам'яті вкладки: після перезавантаження сторінки сайт збирається заново, зміни не зберігаються. Це нормально для демо.

Варіанти посилання:

- `&mode=seamless` — без рамки Playground, схоже на справжній сайт.
- Для іншої гілки або форку змініть `url`/`ref` у `blueprint.json`.

## Локальний запуск

Потрібен лише Node.js (18+; на Node 22 CLI пише попередження про версію, але працює).

```bash
npm start
```

Це те саме, що:

```bash
npx @wp-playground/cli@latest server \
  --blueprint=blueprint.local.json \
  --mount=./theme/prostir:/wordpress/wp-content/themes/prostir \
  --port=9400
```

Сайт: http://127.0.0.1:9400 — адмінка: http://127.0.0.1:9400/wp-admin/ (автологін).
Папка теми примонтована, тож зміни в PHP/CSS/JS видно одразу після оновлення сторінки. Щоб перевірити встановлення з нуля, просто перезапустіть команду.

Перевірити публічний blueprint локально (тема береться з GitHub, а не з папки):

```bash
npm run start:public
```

## Що редагується в адмінці

Меню **«Простір»** в адмінці збирає все в одному місці:

| Розділ | Що змінюється |
| --- | --- |
| Контакти і тексти (Customizer) | назва, адреса, телефон, Instagram, години, карта, ціна оренди, тексти всіх секцій головної, фото hero/сертифіката/друку/оренди/CTA |
| Пакети | ціна, тривалість, учасники, образи, список «що входить», текст кнопки, позначка «Найпопулярніший», показ на сторінці сертифікатів |
| Види фотосесій | фото, короткий опис, галерея, відповідні пакети, показ на головній |
| Портфоліо | фото + напрямок; на головній показуються перші 16 (кількість у Customizer) |
| Можливості студії | фото, назва, підпис |
| Відгуки | ім'я, текст, тип фотосесії |
| Заявки | усі відправлені форми (ім'я, телефон, пакет, дата, коментар) |
| Сторінки | Оренда, Сертифікат, Про студію — звичайний редактор блоків |

Кнопка **«Перевстановити демо-контент»** на сторінці «Огляд» повертає початковий стан.

## Форма запису

Форма відправляє заявку на `POST /wp-json/prostir/v1/lead` (без JS працює звичайний POST через `admin-post.php`). Заявка зберігається в розділі «Заявки». Відправку на e-mail або в Telegram додають одним хуком:

```php
add_action( 'prostir_lead_created', function ( $lead_id, $lead ) {
	wp_mail( get_option( 'admin_email' ), 'Нова заявка: ' . $lead['name'], print_r( $lead, true ) );
	// Telegram: wp_remote_post( "https://api.telegram.org/bot{TOKEN}/sendMessage", [ 'body' => [ 'chat_id' => CHAT_ID, 'text' => ... ] ] );
}, 10, 2 );
```

## Структура теми

```
theme/prostir/
├── functions.php            підключення модулів
├── inc/
│   ├── setup.php            підтримка функцій, меню, розміри зображень, скрипти
│   ├── post-types.php       CPT: пакети, види фотосесій, портфоліо, можливості, відгуки, заявки
│   ├── meta-boxes.php       поля записів без ACF (ціна, галерея, пакети…)
│   ├── customizer.php       усі тексти й контакти з дефолтами з ТЗ
│   ├── template-tags.php    хелпери: ціни, кнопки, іконки, запити
│   ├── form.php             REST-ендпоінт заявки + хук prostir_lead_created
│   ├── admin.php            меню «Простір», сторінка огляду, віджет
│   └── demo-content.php     сідер демо-контенту (викликає blueprint)
├── templates/               шаблони сторінок: фотосесії, оренда, сертифікат, студія, контакти
├── template-parts/home/     секції головної (hero, переваги, пакети, портфоліо…)
├── template-parts/components/  форма запису, шапка внутрішньої сторінки
└── assets/                  css, js, шрифти (Manrope, Inter), демо-фото (WebP)
```

Фото в демо з Pexels, деталі в [theme/prostir/CREDITS.md](theme/prostir/CREDITS.md).

## Що свідомо не зроблено в демо

SEO (title/description, Schema, sitemap), аналітика, реальна відправка заявок, онлайн-календар і передоплата. Архітектура (CPT, таксономія напрямків, хук заявок) дозволяє додати це без переробки.
